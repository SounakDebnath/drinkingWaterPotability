# Drinking Water Potability Prediction Model  
Uploaded: 11/01/2026  
Description: This is a Random Forest Model that predicts the water potability of water samples given chemical water quality parameters. It includes an interactive UI that allows users to choose between five pre-set samples as well as input their own measured parameters

This code runs on Python 3.0+

Required Python Libraries:  
pandas  
numpy  
matplotlib  
scikit-learn  
joblib  
ipywidgets  
IPython  
seaborn  

File Summaries:  
Drinking_water.ipynb trains and tests the model, and saves it to RandomForest_Potability.pkl  
confusion_matrix.png and roc_curve.png are both image files generated by Drinking_water.ipynb  
The original dataset (water_potability.csv) is randomly split into the training data (train.csv) and testing data (test.csv)  
The model's predictions for the training data and the testing data are saved in train_pred.csv and test_pred.csv,  respectively.  
The interactive UI is found in Drinking_water_quality_prediction.ipynb.
